用量汇总 按本机时区累计；字节 = 信封上行 + 下行

凭据与用量 日 / 月 / 总次数与流量，分钟限速及年流量

首次不会自动生成凭据；点击生成，可创建多个。留空 = 继承全局默认；分钟次数和流量必须大于 0，其余额度填 0 = 不限。服务器只存 sha256，明文仅生成时显示。删除需输入名称确认。
次数 = 有效凭据的业务请求（含拒绝/失败）；流量 = 实际入队与取走的 UTF-8 信封字节之和，不含 HTTP 开销。失败只记实际发生的用量；分钟限速与速度统计共用最近 60 秒窗口。重启清空分钟窗口，不清累计额度。

安全边界

本机管理：管理页只接受本机回环直连（127.0.0.1 / ::1），Host 必须是回环名，拒绝跨站请求；管理写操作必须是 JSON。 业务面仍需 Authorization: Bearer <凭据>，心跳/取信/下线还需 Ed25519 签名。消息只在内存队列停留 30 秒，不落盘。 TLS 默认自签并固定指纹；非回环的明文业务请求一律 426。磁盘不保存凭据明文：被扩网凭据只存 sha256，出网凭据 AES-256-GCM 加密（密钥在本机 secret.key 或 FWARMY_MASTER_KEY）。 最坏情况：拿到整机文件系统（或 secret.key）的人可解密出网凭据；同一台机器上的其它本地进程/用户可以调用本机管理接口。不要把服务器放在多人共用机器上，也不要把管理端口映射到公网。
